# ADR-168: bme280, one forced sample from a Bosch BME280 over I2C

**Status:** Proposed
**Date:** 2026-10-07
**Cog:** `bme280` 0.1.0

## Context

Catalog module `bme280` is a Bosch BME280 temperature, humidity, and pressure sensor. Its `cogs` list is empty. The interface in the catalog is I2C at 0x76 or 0x77, or SPI. The datasheet cited there is BST-BME280-DS002. This cog is the I2C reader. SPI is not implemented.

The compensation integers are the non-floating path in Bosch Sensortec's BME280 driver v3.5.1, dated 2020-12-17 (`bme280.c`: temperature, 64-bit pressure, humidity). The register parser matches that driver: chip id `0xD0` must be `0x60`, calibration at `0x88` (26 bytes) and `0xE1` (7 bytes), data burst at `0xF7` (8 bytes). A BMP280 id `0x58` and a BME680 id `0x61` are refused.

`cog_lint.py` accepts only `pi-zero-2w` and `v0-appliance` in `hardware_requirement`. Those are the ids this cog declares. The bus is I2C.

The catalog file is not edited. This package does not change the catalog digest.

## Decision

1. One forced measurement per sample. After the chip id matches, write `ctrl_hum` (`0xF2`) = `0x01` and `ctrl_meas` (`0xF4`) = `0x25` (temperature x1, pressure x1, forced). Wait 20 ms. Read the burst. No soft reset.
2. `--simulate` runs the same decoder and compensation on a fixed image. The stdout line says `status` `simulate` and `provenance` `SYNTHETIC`. The temperature of that image is 25.08 °C.
3. No device, or a chip id that is not `0x60`: one `no_source` line, null readings, process exit 0 on `--once`. The error names the next check (bus node, address, SDO, power-cycle). A non-Linux build says I2C is not opened on that host.
4. Stdout is one JSON object per sample. There is no HTTP server in this version. `[api] bind_port` is 8054, loopback only, reserved for a later export.
5. Console commands are `--once`, `--once --simulate`, and `--help`.

## Consequences

- A real reading requires Linux I2C and a part whose chip id is `0x60`. This repository has no on-device run of this cog.
- Oversampling is fixed at x1. The catalog's self-heating note still applies if someone later raises the rate.
- Spatial evidence does not apply. The part reports ambient air, not a position.

## Verification

Unit tests pin the integer compensation and the register round-trip. `cog-bme280 --once --simulate` prints the 25.08 °C line. `cog-bme280 --once` on a machine with no I2C node prints `no_source`. The cross-build is the release-system check for this package.
